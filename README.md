# HunMaster Command Center

Создай современную премиальную **HunMaster Admin Panel** — административную панель для управления будущей платформой курсов венгерского языка HunMaster.

ВАЖНО: на данном этапе админ-панель должна быть ТОЛЬКО качественным интерактивным макетом.

Пока НЕ подключай:
— Supabase;
— базу данных;
— настоящую авторизацию;
— API;
— платежные системы;
— реальное создание пользователей.

Используй mock/demo data, но построй архитектуру интерфейса так, чтобы позже можно было легко подключить настоящий backend.

==================================================
ДИЗАЙН
==================================================

Админ-панель должна продолжать визуальный стиль HunMaster.

Не делай стандартную скучную admin dashboard.

Мне нужен интерфейс уровня современного premium SaaS:

— минимализм;
— Liquid Glass;
— глубокий dark background;
— бордовые / тёмно-коричневые оттенки;
— кремовый текст;
— красно-оранжевые акценты;
— очень небольшие зелёные accents;
— много свободного пространства;
— аккуратная типографика;
— дорогие micro-interactions.

Основной шрифт:

Manrope

Для отдельных крупных цифр / акцентов можешь использовать:

Unbounded

Используй Lucide React icons.

Никаких emoji.

Анимации реализуй через Framer Motion.

Animation should feel expensive, not excessive.
